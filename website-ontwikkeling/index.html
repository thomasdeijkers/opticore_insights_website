Veelgestelde vragen

Is de website volledig in HTML?

De pagina’s worden in HTML gebouwd. CSS verzorgt de vormgeving en JavaScript de interactie. Voor het verwerken van formulieren kan een klein PHP-onderdeel worden gebruikt, zoals bij Home Assistant hub.

Kan de website meerdere talen krijgen?

Ja. Per taal kunnen eigen pagina’s worden gemaakt, met een herkenbare taalkeuze en verwijzingen naar de andere versies. Bij Home Assistant hub is dat uitgewerkt voor Nederlands, Engels en Duits.

Wat doe je voor de vindbaarheid?

Elke pagina krijgt een duidelijke titel, metaomschrijving en koppen. We richten de interne links, canonieke URL’s en sitemap in. Die helpen zoekmachines de inhoud begrijpen; een positie in Google is niet vooraf te beloven.
