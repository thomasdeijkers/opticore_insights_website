Uitleg en mogelijkheden

Bestaande systemen met elkaar koppelen

We halen verkoopdata, inkoopgegevens, voorraad en andere informatie automatisch via API’s op. Je dashboard en webapp blijven volgens afspraak bijgewerkt, zonder terugkerende bestandsimports.

Automatisch van bron naar dashboard

Wat is een API en hoe halen we daarmee gegevens op?

Een API is een afgesproken digitale toegang waarmee programma’s gegevens kunnen opvragen of uitwisselen. Met jouw toestemming verbinden we bijvoorbeeld de API van je webshop, inkoopprogramma of magazijn met je dashboard. De koppeling haalt de afgesproken gegevens op; je hoeft daarvoor geen Excel- of CSV-bestanden te exporteren en te uploaden.

  1. Toegang en gegevens afspreken

    We controleren de API van de leverancier: welke verkoopregels, inkoopgegevens, voorraad of andere informatie is beschikbaar? Welke historie mogen we ophalen? We richten alleen de benodigde rechten in. Voor gegevensophaling gebruiken we waar mogelijk toegang waarmee we alleen kunnen lezen.

  2. Historie ophalen en verbinden

    Bij de eerste inrichting halen we de beschikbare historie via de API op. We vertalen velden en statussen, verbinden artikelen en orders en controleren aantallen en totalen. Zo komen verkoopdata, inkoopprijzen en voorraad uit verschillende systemen in hetzelfde overzicht terecht.

  3. Automatisch blijven bijwerken

    Daarna vraagt de koppeling op afgesproken momenten nieuwe en gewijzigde gegevens op. Ondersteunt het systeem webhooks, dan kan een melding over bijvoorbeeld een nieuwe order een update starten. De snelheid hangt af van de API, het abonnement en de afgesproken inrichting.

Ook de verwerking achter de cijfers moet kloppen.

Controle op volledigheid en actualiteit

We houden bij welke gegevens al verwerkt zijn en wanneer een bron voor het laatst is bijgewerkt. De koppeling verwerkt gegevens in passende hoeveelheden, houdt rekening met gebruikslimieten en voorkomt dubbele verwerking. Fouten of ontbrekende gegevens maken we zichtbaar.

Wanneer een leverancier tijdelijk niet bereikbaar is, plannen we waar passend een nieuwe poging. We tonen dat een bron nog niet actueel is, zodat oudere cijfers niet ongemerkt als een nieuwe stand worden gepresenteerd.

Afgeschermde toegang en duidelijke rechten

We bewaren de benodigde API-sleutels en toegangstokens afgeschermd op de server. Gegevens ophalen en wijzigingen terugschrijven zijn afzonderlijke afspraken. Orders plaatsen, voorraad aanpassen of campagnes wijzigen activeren we alleen binnen de afgesproken rechten en controles.

Een testbestand alleen tijdens de opstart

Om snel de werking van een dashboard of module te laten zien, kunnen we tijdens een tijdelijke test een aangeleverd Excel- of CSV-bestand gebruiken. Daarmee toetsen we de weergave, definities en berekeningen voordat de definitieve koppeling gereed is.

Voor dagelijks gebruik richten we automatische API-koppelingen in. Een testimport is geen terugkerende manier om het dashboard bij te werken. Voor de ingebruikname controleren we de gegevens uit de API opnieuw, stemmen we de beschikbare historie af en testen we de automatische updates.

Heeft een programma geen API, of geeft jouw account niet de benodigde toegang? Dan bespreken we eerst de mogelijkheden met jou en eventueel de leverancier. We maken vooraf duidelijk welke bron aangesloten kan worden en welke informatie daardoor beschikbaar komt.

Verdiep je verder

  • REST API-koppelingen →

    Veel bedrijfssoftware biedt een REST API om gegevens op te halen of bij te werken. Daarmee kunnen bestaande systemen gericht met elkaar worden verbonden.

  • Webhooks →

    Een webhook geeft een melding zodra er in een systeem iets gebeurt. Een nieuwe order kan zo de start zijn van een volgende stap in een ander systeem.

    Als een automatische taak niet loopt, wil je weten waar dat aan ligt. Logging legt gebeurtenissen vast; monitoring maakt de status van taken zichtbaar.
